# Kemal Yasintha — Engineering Portfolio

A recruiter-focused portfolio for Kemal Yasintha, a Senior Software Engineer specializing in .NET, Azure, API development, SaaS modernization, CI/CD, and production-quality delivery.

## Highlights

- React 19 and Next.js 15 portfolio site
- Responsive layout, dark mode, and accessible outbound links
- Curated public engineering projects with technology context
- Direct email and LinkedIn contact options

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Run a production build before deploying:

```bash
npm run build
```

## Deployment

The site is configured as a standard Next.js application and can be deployed on Vercel.
